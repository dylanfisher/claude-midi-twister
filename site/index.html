Visual overview of your Claude sessions

A daemon that shows every running Claude Code session on a DJTT Midi Fighter Twister, one encoder per session. The color is the session's state, the LED ring is how long the current turn has run, and pressing an encoder brings that session's terminal tab to the front. The device is display-only: it cannot answer a prompt or approve a tool call.

4 banks × 16 encoders = 64 sessions Python 3.14, stdlib + mido macOS MIT

Below is that render loop — render.py, board.py, overlays.py, font.py — ported line for line, running against a simulated terminal instead of a MIDI port. It runs one scenario at a time on its own, and the scenario it is running stays lit in the row below. Click an encoder, press a scenario, or type a prompt to drive it yourself.

What the colors mean

Ten states, one color each. Hover a row to play that state alone. The colors, animation rates and ring rules below come from the same tables the daemon uses — mft/config.py, ported line for line.

    Get it

    Installing

    THE HARDWARE DJ TechTools — Midi Fighter Twister → 16 RGB-lit rotary encoders with LED rings, 4 banks, USB class-compliant. The device this daemon drives. THE FAMILY midifighter.com → Twister, Spectra, 3D, Classic: the utility, the firmware, and the rest of the Midi Fighter line. THE SOFTWARE github.com/dylanfisher/claude-midi-twister → Python 3.14, stdlib only except mido + python-rtmidi. The README is the design document. 
    # install. it backs up your settings first and tags its own entries,
# so --uninstall removes exactly what it added
$ python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
$ .venv/bin/python install_hooks.py --print   # look at what it will add
$ .venv/bin/python install_hooks.py           # merge into ~/.claude/settings.json

# run it and leave it running. any Claude Code session claims an encoder.
$ .venv/bin/python -m mft.daemon

# or build the app bundle, which starts and stops the daemon
$ .venv/bin/python app/make_app.py            # -> ~/Applications/Claude Twister.app

# without hardware, everything except the wire still runs
$ .venv/bin/python -m mft.daemon --no-device
$ .venv/bin/python -m mft.simulate --sessions 6

    One more step: in the Midi Fighter Utility, set the encoders to accept host LED control. Otherwise the device drives its own LEDs and ignores everything the daemon sends.

    Built for the DJ TechTools Midi Fighter Twister. Not affiliated with DJ TechTools or Anthropic. The simulator above is a port of the daemon's pure modules. Its colors are approximations of the device's hue wheel: the wheel is a property of the LEDs, and there are no hex values anywhere in the repo.
